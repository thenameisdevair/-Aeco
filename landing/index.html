The Story

Aeco was built in a few weeks as part of Web3Bridge Cohort XIV — a rigorous blockchain development program covering EVM internals, account abstraction, ZK proofs, and smart contract security. The question was simple: can an AI agent be a reliable, verifiable oracle on Celo? The answer is running on mainnet.

This is early. The oracle covers 8 subjects today. The infrastructure is designed to scale to hundreds. As AI agents proliferate on Celo, they will need trusted on-chain data sources. Aeco is building that layer.
